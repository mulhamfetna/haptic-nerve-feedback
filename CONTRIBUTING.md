# Contributing

Thanks for your interest! This is an early-stage open research project — contributions of
*knowledge* are as valuable as code right now.

## Ways to contribute

- **Research sources** — know a paper, patent, product, or lab we missed? Open an issue
  with the *Research source* template. Please link the original (we do not accept
  copyrighted PDFs into the repo).
- **Replication & experiment notes** — tried electrotactile / nerve-stimulation hardware?
  Use the *Experiment* template; include full stimulation parameters (waveform, pulse
  width, frequency, amplitude, electrode placement) so results are reproducible.
- **Safety review** — corrections or additions to our safety assumptions are always
  priority; label them `safety`.
- **Code & hardware** (as the project matures) — open an issue before large PRs so we can
  align on the roadmap stage (H1–H4 / software stages in [ROADMAP.md](ROADMAP.md)).

## Ground rules

- Everything contributed is licensed under **AGPL-3.0-or-later** (code/designs) — by
  submitting a PR you agree to this.
- No copyrighted third-party material (paper PDFs, video transcripts) in the repo — link
  to the original instead.
- Safety claims need a citation. Anything involving stimulation of a human body must stay
  within TENS-class limits and biphasic charge-balanced waveforms.
- Milestones track the hardware stages (H1 Ring → H4 Spine patch); label issues with the
  stage they belong to.
